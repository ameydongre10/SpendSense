# SpendSense: Enterprise Payments Network Analytics & Fraud Risk Intelligence Platform

## Project Overview
SpendSense is a production-grade transaction analytics and fraud-risk intelligence system built to global card payment network standards (Mastercard / Visa scheme analytics). It processes 284,807 transactions (0.1727% fraud prevalence) across 18 calendar months, resolving severe class imbalance through cost-sensitive XGBoost modeling, AUPRC threshold optimization, RFM quintile segmentation, 18-month cohort retention matrices, customer segment unit economics, explainable statistical anomaly detection, and quantified executive recommendations.

## Tech Stack
- **Backend:** Python 3.11/3.14, FastAPI (ASGI async), Pydantic v2, SQLAlchemy 2.0
- **Database:** Dual-Engine architecture (PostgreSQL primary with automated SQLite embedded fallback)
- **Machine Learning & Analytics:** Scikit-Learn, XGBoost, Pandas, NumPy, Joblib
- **Frontend Architecture:** Swiss Modernist Industrial Fintech Terminal (High-density telemetry, tabular numerals, dark graphite `#0B0F17`, cyan-emerald `#00E599` / `#00B4D8` risk indicators, WCAG AA contrast compliance)
- **Deployment & Ops:** Docker multi-stage build, GitHub Actions CI/CD, Vercel Serverless & Render compatibility

## Core Business & Analytical Pillars
1. **Pillar 01:** Fraud Rate Trajectory & Monthly Loss Trends
2. **Pillar 02:** Merchant Category Spend Volume & Concentration Mix
3. **Pillar 03:** RFM Customer Value Segmentation (Quintile Scoring)
4. **Pillar 04:** Cohort Lifecycle Decay & Retention Matrix
5. **Pillar 05:** Customer Segment Profitability & Unit Economics Simulator
6. **Pillar 06:** Explainable Billing Anomaly Detection (Category Z-Score & 4x IQR)
7. **Interactive Risk Decision Simulator:** Real-time Precision-Recall operating point slider with avoided revenue-at-risk impact.
